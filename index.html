只跑一次阶段一 · context_build
STAGE1 · 01
DataStore.load
加载 FD-0332~0374（MR）与 FD-0258~0331（工参），这批原始观测后续在阶段二里被反复复用，不会每个候选重新读一次。
STAGE1 · 02
M-001 / M-002（条件触发）
字段齐全就跳过：补全缺失的 FD-0343/0345/0348/0350，定位输出 FD-0800 / FD-0801 坐标。
STAGE1 · 03
M-003 栅格化
按 FD-0800/0801 把样本落到 100m×100m 网格，产出栅格级空间特征，供 M-004 做角度功率谱标定。
STAGE1 · 04
M-004 calibrate
对每个 (栅格, 小区) 反解角度功率谱（PAS）——与天线朝向无关，标定一次，供阶段二所有候选共用。
反复执行阶段二 · candidate_evaluation
STAGE2 · 01
Optimizer.ask()
生成候选 Δ方位角 / Δ下倾角 / Δ功率——对应工参里的 FD-0282 / FD-0284 / FD-0297（PlannerAgent 已校验过这几个字段确实登记在 M-004 输入里）。
STAGE2 · 02
M-004 predict + M-008
标定好的 PAS 不变，只用新 Δ 重算增益矩阵并相乘，得到反事实电平 FD-0343/0348；M-008 据此算出谱效 FD-0371。
STAGE2 · 03
KPI 聚合 + 打分
把全场景的电平 / 谱效聚合成弱覆盖占比、边缘谱效、平均谱效、重叠覆盖度四项，代入 coverage_score()。
STAGE2 · 04
约束检查
硬约束（参数改动幅度）和软约束（KPI 相对基线不能变差太多）都通过才算 feasible，否则这个候选直接出局。
optimizer.tell(result) 把这一轮的 score 反馈给优化器（坐标下降 / 随机搜索），决定下一个候选往哪个方向走——这是循环真正跑起来的地方，上面四步每轮候选都重新算一次，直到 trials 用尽。

打分公式：coverage_score

四项各自归一化后加权求和，FD-0371 谱效在这里被用了两次（边缘 / 平均），弱覆盖占比权重最高。
coverage_score =
  − 1.00 × weak_coverage_ratio  // 弱覆盖占比，权重最高
  + 0.50 × edge_SE / SE_MAX  // 边缘用户体验（FD-0371 的 P5 分位）
  + 0.20 × mean_SE / SE_MAX  // 全网平均吞吐（FD-0371 的加权均值）
  − 0.15 × overlap_ratio  // 重叠覆盖惩罚

约束：候选要同时过两道检查

硬约束 · 参数变更幅度

只看候选本身，与 KPI 无关，算完就能判断
  • FD-0282 方位角变更 ≤ max_azimuth_change_deg
  • FD-0284 下倾角变更 ≤ max_tilt_change_deg
  • FD-0297 发射功率变更 ≤ max_tx_power_change_db
  • 改动小区数 ≤ max_changed_cells

软约束 · KPI 相对基线恶化

要等 M-004 / M-008 算完 KPI 才能判断
  • 同频干扰上升幅度 ≤ max_interference_increase
  • 弱覆盖恶化幅度 ≤ max_weak_coverage_increase

进入打分的数值，调用的是模型还是 baseline 公式

环节官方设计现在实跑说明
M-004 电平预测 RF-LSCM（角度功率谱反事实重合成） 真实算法 复用官方 baseline 的 WNNOMP 稀疏标定算法，FD-0343/0348 不是占位替身
M-008 谱效计算 DiffusionSE 神经网络（扩散模型） baseline 替身 torch 环境未接通，FD-0371 暂用截断香农公式代替，接口字段不变
M-001 / M-002 补全 / 定位 ChaRT（Transformer 补全 / 定位） baseline 替身 暂用偏置回归、加权质心公式近似；真实权重已就位但接线未确认
排序取分位数 — 纯算法 numpy 排序 + grid_weight 加权累积，不涉及模型，排的是上面算出的数值
关键在于阶段拆分，不是模型本身：M-004 被拆成 calibrate（阶段一只跑一次，反解 PAS）和 predict（阶段二每候选都跑，换增益矩阵重合成）——这是整条闭环能把候选评估压到毫秒级、 支撑坐标下降跑完几十上百次候选的根本原因；PAS 本身与朝向无关，所以改 FD-0282/0284 只需重算增益矩阵再乘，不需要重新标定。
